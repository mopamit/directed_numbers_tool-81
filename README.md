# כלי עזר במספרים מכוונים — Prismind

יישומון עצמאי לתלמידים לתרגול וחישוב על ציר מספרים מכוונים.

## תכונות
- טווחים: ±10, ±15, ±20, ±25.
- בחירת כל מספר על הציר כמיקום נוכחי.
- קביעת כל מספר כנקודת התחלה נפרדת.
- תנועה בקפיצות של 1 בלבד.
- מעבר בין תצוגה אנכית (מעלית) לתצוגה אופקית — תצוגה אחת בכל פעם.
- סימון נפרד לנקודת התחלה ולמיקום הנוכחי.
- פונט SimplerPro ועיצוב Prismind.
