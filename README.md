# חיבור וחיסור במודל המעלית — Prismind

יישומון חקר בעברית ו־RTL, עם Simpler Pro וצבעי פריזמה.

## שימוש
- טווחים: ±10, ±15, ±20, ±25. צמצום הטווח מגביל גם את המיקום ונקודת ההתחלה.
- לחיצה על מספר בוחרת מיקום. עלייה מוסיפה 1 וירידה מחסירה 1; גם חצי המקלדת נתמכים.
- אפשר לקבוע נקודת התחלה, לחזור אליה ולבטל אותה בלי להזיז את המיקום. בתחילה אין נקודת התחלה.
- הבית מאפס לטווח ±10, מיקום 0 ומעלית, ומבטל נקודת התחלה ואתגר פעיל.
- הציר האופקי מתמרכז בהחלפת תצוגה/טווח או בבחירת אתגר בלבד. בתנועה הוא נשאר קבוע; למספרים שמחוץ לחלון גוללים ידנית.
- „אתגרים” מציג את ששת האתגרים מה־PDF לבחירה בכל סדר. הבחירה מכינה את נקודת ההתחלה ומשאירה את השאלה גלויה. התרגיל הראשון מרחיב את הטווח לפחות ל־±15, כי המסלול מגיע ל־14.
- אין ניקוד, בדיקת תשובות או סדר שלבים. יישומון הדילוגים אינו חלק מהגרסה הזאת.

## גרסה צרה
אותם קבצים מציגים רק את המעלית וכפתורי התנועה באמצעות `?view=compact`:

```html
<iframe src="https://mopamit.github.io/directed_numbers_tool-81/?view=compact"
  title="חיבור וחיסור במודל המעלית" width="280" height="700"
  style="border:0;max-width:100%"></iframe>
```

הקישור הציבורי ישקף את התיקון אחרי מיזוג ופרסום GitHub Pages. מצב זה מתחיל בטווח ±10, ללא כותרת והגדרות, ותומך בבחירת קומה ובתנועה בכפתורים ובמקלדת.

## הרצה ובדיקות
ללא תלויות או שלב בנייה. הריצו `python3 -m http.server 8765` בשורש הריפו ופתחו `http://localhost:8765`.

בוצעו בדיקת תחביר `node --check app.js` ובדיקות ידניות בדפדפן: תנועה, בחירת קומה, קביעת/ביטול/חזרה להתחלה, ציר אופקי קבוע, כל ששת האתגרים ונקודות ההתחלה שלהם, הרחבת הטווח בתרגיל הראשון, גבולות ±10, איפוס, עזרה ו־Escape. חצי המקלדת אינם מזיזים את המעלית כשהחלון פתוח. נבדקו תצוגת מחשב ברוחב 1280, טלפון ברוחב 360 והטמעה ברוחב 280, כולל כיוון הנוסחאות. לא נמצאו שגיאות JavaScript ביומן הדפדפן.

## נכסים
נשמרו הגופנים והלוגו שבריפו. תיקיית `prisma` ב־Drive אותרה, אך לא התקבלו ממנה קבצים זמינים, ולכן נשמרו נכסי המיתוג הקיימים.
